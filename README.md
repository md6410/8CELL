# 8CELL — مدیریتِ کسب‌وکار

سامانهٔ تحت‌وبِ مدیریتِ کسب‌وکار با **هستهٔ فروشِ حضوری** (PHP 8 + MySQL، مناسبِ هاستِ cPanel)؛ فروشگاهِ آنلاین **ماژولِ افزودنی** است که مثلِ یک فروشنده از راهِ «کانال‌های فروش» به هسته وصل می‌شود.

- نصب روی cPanel: [docs/install-cpanel.md](docs/install-cpanel.md)
- ساختِ ماژول و جای فروشگاهِ آنلاین: [docs/modules.md](docs/modules.md) · API کانال‌ها: [docs/channels-api.md](docs/channels-api.md)
- ایستگاهِ چاپ: [docs/print-agent.md](docs/print-agent.md)

## هم‌سانی با Weby
از نسخهٔ ۱٫۱ این بخش‌ها از کدِ آزموده‌شدهٔ Weby برداشته یا با آن هم‌سان شده‌اند: پیامک SMS.IR و OTP، Passkey، اسکنرِ دوربین (`scan-box.js`)، ایستگاهِ چاپ (`print-api.php` + همان WebyPrint)، کدگذاریِ v2، قواعدِ حقوق، تعطیلات و نرخِ ارز، سقفِ نقدِ کارمند، نگهبانِ قیمت، قیمتِ همکاری و نصبِ زیپِ ماژول.

## توسعه
```
TEST_DB=cell8_test TEST_USER=root php tests/run.php     # آزمون‌های مشخصات (پایگاه‌دادهٔ آزمون خالی می‌شود)
php -S 127.0.0.1:8088                                    # اجرای محلی؛ سپس install.php
```
`8CELL.pm.json` طرحِ پروژه برای Milo است (همراه با work_report).
