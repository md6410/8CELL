# 8CELL — مدیریتِ کسب‌وکار

سامانهٔ تحت‌وبِ مدیریتِ کسب‌وکار با **هستهٔ فروشِ حضوری**؛ فروشگاهِ آنلاین **ماژولِ افزودنی** است که مثلِ یک فروشنده به هسته وصل می‌شود.

## طرحِ پروژه (برای Milo)

`8CELL.pm.json` طرحِ کاملِ پروژه است: در Milo از «ایمپورت از فایل…» (یا «نمونه‌ها و ماژول‌های آماده» از نسخهٔ ۲٫۹) واردش کنید.

| # | بخشِ کلی | ماژول‌ها |
|---|---|---|
| ۱ | هسته، تنظیمات و گسترش | تنظیماتِ کسب‌وکار/شعبه/سالِ مالی/ممیزی، تقویم و نرخ، موتورِ ماژول، به‌روزرسانیِ خودکار |
| ۲ | کاربران، ورود و پیامک | کاربران و نقش‌ها، ورودِ بی‌رمز، پیامک SMS.IR |
| ۳ | کالا، خرید و انبار | کالا و قیمت، خرید و تأمین‌کننده، انبارِ چندگانه، اسکن، برچسب، چاپگرِ مرکزی |
| ۴ | فروشِ حضوری، فاکتور و کانال‌ها | صندوق و شیفت، قیمتِ همکار، فاکتورساز، کانال‌های فروش |
| ۵ | کارکنان و منابع انسانی | حساب/پورسانت/عملکردِ فروشنده، پرونده، حضور، مرخصی، حقوق |
| ۶ | مشتریان و ارتباط | پروندهٔ مشتری، نسیه و کیف پول، تماس و پیگیری |
| ۷ | مالی و حسابداری | دفترِ مالیِ مرکزی (سندِ خودکار، بانک/چک، اشخاص)، سهمِ شرکا |
| ۸ | گزارش‌ها و داشبورد | داشبوردِ روز، سود و زیان، گزارش‌ساز |
| ۹ | ماژولِ افزودنی: فروشگاهِ آنلاین | اتصال به هسته، سبد و سفارش، هستهٔ پرداخت + ۷ درگاه، ارسال، نقشه، ترب |

منبع: `Invora_—_دفترِ_فاکتور.pm.json` و `فروشگاه_ساز_Weby.pm.json` (خروجیِ Milo). سازندهٔ طرح در مخزنِ Milo است (`tools/library/p03_8cell.py`).
