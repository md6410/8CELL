# نصب روی هاستِ cPanel

**نیازها:** PHP 8.0 یا بالاتر (پیشنهاد 8.2) با افزونه‌های `pdo_mysql`، `mbstring`، `openssl`، `curl`، `zip`، `gd` (برای کپچا) · MySQL 5.7+/MariaDB 10.3+ · HTTPS (برای دوربین و Passkey الزامی است).

1. **پایگاه‌داده:** در cPanel ← *MySQL® Databases* یک پایگاه‌داده و یک کاربر بسازید و کاربر را با *ALL PRIVILEGES* به پایگاه‌داده وصل کنید. کدگذاری پیش‌فرض (utf8mb4) را نگه دارید.
2. **فایل‌ها:** محتوای مخزن را (یا زیپِ شاخهٔ `main`) در پوشهٔ مقصد آپلود کنید، مثلاً `public_html/8cell`. پوشهٔ `data/` باید قابلِ نوشتن باشد (۷۵۵).
3. **نسخهٔ PHP:** در *MultiPHP Manager* (یا *Select PHP Version*) برای دامنه PHP 8.1+ را انتخاب کنید و افزونه‌های بالا را روشن کنید.
4. **نصب:** `https://دامنه/8cell/install.php` را باز کنید؛ اطلاعاتِ پایگاه‌داده، نشانیِ سایت و مدیر را وارد کنید. نصب‌کننده `config.local.php` را می‌سازد، جدول‌ها را می‌سازد و پس از آن قفل می‌شود.
5. **Cron (به‌روزرسانیِ خودکار):** در cPanel ← *Cron Jobs* هر ۱۰ دقیقه:
   ```
   curl -s "https://دامنه/8cell/index.php?p=cron&k=کلیدی-که-نصب‌کننده-نشان-داد"
   ```
   (بدونِ Cron هم با هر بازدیدِ مدیر بررسی می‌شود.)
6. **مخزنِ خصوصی:** اگر مخزنِ `md6410/8cell` خصوصی است، یک توکنِ *fine-grained* فقط‌خواندنی (Contents: Read) بسازید و در «تنظیمات ← به‌روزرسانی» یا هنگامِ نصب وارد کنید.
7. **پس از نصب:** «تنظیمات ← پروفایلِ کسب‌وکار»، «اطلاعاتِ پایه» (شعبه، انبار، صندوق، دسته، واحد)، «سالِ مالی»، «کاربران و نقش‌ها»، «پیامک» (کلید و شناسهٔ قالب‌های SMS.IR؛ تا آن زمان حالتِ آزمایشی روشن است).

**امنیت:** `.htaccess` دسترسیِ مستقیم به `inc/`، `data/`، `tests/`، `tools/` و `config.local.php` را می‌بندد (روی LiteSpeed/Apache). اگر سرورِ شما nginx است، همین مسیرها را در پیکربندی ببندید.

**پشتیبان:** از پایگاه‌داده (phpMyAdmin ← Export) و پوشهٔ `data/` پشتیبان بگیرید. به‌روزرسانی هرگز `data/` و `config.local.php` را لمس نمی‌کند.
