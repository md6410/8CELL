# ایستگاهِ چاپ (چاپگرِ مرکزی)

8CELL همان پروتکلِ ایستگاهِ چاپِ Weby را دارد (`print-api.php`: `hello` / `claim` / `status`)، پس **همان برنامهٔ ایستگاهِ Weby** (`tools/print-agent/agent.py` — همان WebyPrint) بی‌تغییر به 8CELL هم وصل می‌شود. یک ایستگاه می‌تواند هم‌زمان برای چند سایت (Weby و 8CELL) چاپ کند.

1. در 8CELL: «چاپگرِ مرکزی ← ساختن و گرفتنِ توکن». توکن فقط یک بار نمایش داده می‌شود.
2. در برنامهٔ ایستگاه یک «سایت» تازه بیفزایید: نشانی `https://دامنه/8cell/print-api.php` و همان توکن.
3. پرینترها و کاغذِ هرکدام (یا چندکاغذی) را در صفحهٔ تنظیماتِ برنامه تعیین کنید؛ سایت کاری را که کاغذش با پرینتر نمی‌خواند اصلاً در صف نمی‌گذارد.

جزئیاتِ نصب، موتورهای رندر (Chrome/Playwright/WeasyPrint)، حالتِ TSPL برای پرینترِ برچسب و اجرای خودکار در ویندوز: `tools/print-agent/README.md`.

ایمنی: نشانیِ صفحهٔ چاپ با `pjob` و `pk` فقط همان سندی را باز می‌کند که کار برایش ساخته شده؛ کارِ «در حالِ چاپ» هرگز خودکار دوباره چاپ نمی‌شود.
